Swiggy is a simple and responsive **food ordering platform frontend** developed using **HTML and CSS**. The project provides a clean and attractive interface where users can explore different food items and browse a simple food menu.

This project was created as a frontend development project to practice webpage structure, styling, responsive layouts, and user-friendly interface design.

 Features

- 🍕 Attractive food ordering interface
- 🍛 Food menu with different food items
- 🖼️ Food images for better visual presentation
- 📱 Responsive webpage design
- 🎨 Clean and simple UI
- 🧭 Easy navigation
- 📋 Food item cards with details
- 💻 Built completely with frontend technologies

## 🍽️ Food Items

The website currently contains food items such as:

- 🍚 Veg Fried Rice
- 🍗 Biryani
- 🍛 Dal Chawal
- 🧀 Paneer
- 🍕 Pizza
- 🫓 Roti

## 🛠️ Technologies Used

- HTML5
- CSS3
